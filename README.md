# Medical Appointment Booking

Medical Appointment Booking is a front-end web application developed for StayHealthy Inc., a nonprofit organization focused on improving access to healthcare services in remote areas.

## Project Purpose

The application is designed to help patients find doctors, book medical appointments, manage their profiles, and provide consultation feedback.

## Phase 1 Features

- Medical appointment booking
- Doctor search and listing
- Consultation feedback and reviews
- User profile management
- Website navigation

## Technologies

- HTML
- CSS
- JavaScript
- React
- GitHub
- Figma

## Project Status

This project is being developed as part of the IBM Front-End Developer Professional Certificate capstone project.
